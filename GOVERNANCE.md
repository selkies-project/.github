## How changes are made

- Anyone can propose a change through an issue or a pull request. A maintainer reviews each pull
  request before merging it.
- Maintainers can also commit directly. Continuous integration builds and tests every change.
- Maintainers decide when to release, and tag the releases.
- Questions and discussion are also welcome on [Discord](https://discord.gg/wDNGDeSW5F).

## Security

Report vulnerabilities privately, never in public issues: through the repository's Security
Advisories (the preferred route) or the other channels in the [security policy](SECURITY.md).

## Conduct

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).

## Becoming a maintainer

The project needs more maintainers. To help, reach out on Discord or in an issue; the current
maintainers add new ones.
