# .github

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/selkies-project/.github)

The community health files every repository of the
[selkies-project](https://github.com/selkies-project) organization shares. GitHub uses them
wherever a repository does not carry its own:

| File | Purpose |
| --- | --- |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | The code of conduct. |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately. |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | The bug report and enhancement request templates. |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | The pull request description. |
| [`.github/FUNDING.yml`](.github/FUNDING.yml) | The sponsor button. |

A repository that adds even one issue template of its own loses the whole shared set, so the
templates are changed here rather than copied.
